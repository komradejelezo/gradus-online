# ГРАДУС ONLINE v0.1

Полноценный локальный прототип игры для компании из 3–8 взрослых за одним экраном. React 19, TypeScript, Vite. Интерфейс на русском. Без регистрации, бэкенда, платных API, внешних шрифтов и сетевых запросов во время игры.

## Быстрый запуск

Нужен Node.js 20.19+ или 22.12+ (рекомендуется актуальная LTS-версия).

```bash
cd gradus-online
npm install
npm run dev
```

Откройте **http://localhost:5173/gradus-online/** в современном браузере. Если порт занят, Vite напечатает другой адрес. Остановить сервер: Ctrl+C. Для запуска на другом устройстве в домашней сети откройте адрес Network из вывода Vite. Для надёжного совместного экрана удобно подключить ноутбук к телевизору по HDMI и включить F11.

Для воспроизводимой установки из lock-файла можно использовать `npm ci` вместо `npm install`.

## Что работает

- Главное меню, правила, настройки, новая игра и продолжение сохранённой партии.
- 3–8 игроков: имена до 20 символов, 8 цветов, 4 SVG-аватара. Одинаковые имена нужно дополнить прозвищами.
- Псевдоизометрическая арена из пяти неоновых платформ, анимации движения персонажей и появления/переворота карточек.
- Три разные случайные зоны на каждый ход. Перемещение не зависит от кубика.
- 50 оригинальных карточек: по 10 в каждой зоне, без повторов до исчерпания колоды. На границе новых колод последняя карточка также не повторяется сразу.
- Провокация и Хаос: +2 очка; Компания: +2 активному игроку; Дуэль: выбор соперника и ручное подтверждение победителя, +3 победителю.
- Риск: один бросок шестигранного кубика; 4–6 дают +4, 1–3 отнимают 2, счёт не опускается ниже нуля. Результат броска сохраняется сразу, поэтому обновление страницы не даёт перебросить кубик. После броска пропустить ход нельзя.
- Пропуск остальных заданий без штрафа; очки и градус не растут.
- Градусометр 0–100% и пять стадий атмосферы. Выполнение повышает градус на 5%, коллективное задание — на 10%.
- Временные правила Хаоса со счётчиком последующих ходов. Пропуски тоже уменьшают срок. В финале временные правила заканчиваются.
- Необязательные таймеры для отдельных заданий: запуск, пауза, повтор. Таймер не завершает ход автоматически; при перезагрузке он сбрасывается, сама карточка и партия сохраняются.
- При 100% текущий ход завершается. Затем каждый игрок, начиная со следующего по очереди, получает одно из 8 уникальных финальных заданий. Выполнение: +5; пропуск: 0.
- Рейтинг, общая победа при ничьей, шуточные титулы, конфетти, повтор партии с тем же составом.
- Автосохранение в localStorage после изменений, восстановление обычного хода, выпавшего кубика, финала и результатов после перезагрузки. Возвращение в меню сохраняет партию. Новая игра заменяет старую только после запуска настроенного состава.
- Защита от повреждённых сохранений и недоступного хранилища: уведомление вместо пустого экрана. В браузере с запрещённым localStorage можно играть до закрытия страницы.
- Синтезированные звуковые эффекты через Web Audio API, выключены по умолчанию; настройка уменьшения анимации и поддержка системного `prefers-reduced-motion`.
- Адаптивная вёрстка для телефонов, ноутбуков и телевизора; управление мышью и клавиатурой, видимый фокус, нативные модальные диалоги.

Любое задание можно пропустить до броска кубика. Никакие задания не требуют употребления алкоголя; градус показывает активность компании.

## Проверки и сборка

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

Готовая статическая сборка находится в `dist/`. Для проверки production-сборки откройте адрес, который выведет `npm run preview` (обычно **http://localhost:4173/gradus-online/**). Через двойной щелчок по `dist/index.html` ES-модули могут не запуститься: используйте preview или любой статический HTTP-сервер. Игровой бэкенд не нужен.

Проверено в среде разработки:

- TypeScript: успешно.
- Production build: успешно.
- 62 автоматические проверки: игровые правила, все шесть результатов кубика, ограничения действий, независимые колоды, истечение эффектов, ничьи, полные партии на 3 и 8 игроков, восстановление, ошибки localStorage и серверная тестовая отрисовка экранов.
- Интерактивная визуальная проверка в настоящем браузере не выполнена: инструмент управления браузером в текущей среде недоступен. Тестовая отрисовка не заменяет проверку расположения элементов и кликов.

Для визуальной приёмки:

1. Проверьте меню, правила, звук и настройки на ноутбуке и при ширине 375 px.
2. Добавьте игроков, переключите аватары и цвета, запустите партию.
3. Выберите одну из трёх зон. Убедитесь, что персонаж двигается и появляется задание.
4. Проверьте выполнение и пропуск, дуэль с выбранным победителем, один бросок Риска и правило Хаоса.
5. Обновите страницу во время задания и после броска — состояние должно восстановиться.
6. Доведите градус до 100%, завершите финальный круг, проверьте рейтинг и повтор партии.

Сохранение относится к браузеру и адресу сайта. Другой порт или браузер использует другое хранилище. Синхронизации между устройствами нет: игра рассчитана на один общий экран.

## Автоматическая публикация в GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` использует Node.js 22, выполняет `npm ci`, `npm test` и `npm run build`. Pull Request в `main` проходит сборку и тесты без публикации. Каждый push в `main` после успешной сборки публикует каталог `dist/` в GitHub Pages. Есть и ручной запуск через **Actions → Build and deploy to GitHub Pages → Run workflow**, выберите ветку `main`.

Однократная настройка репозитория:

1. Откройте **Settings → Pages → Build and deployment**.
2. В **Source** выберите **GitHub Actions**. Ветка `gh-pages` не нужна.
3. Слейте Pull Request с настройкой публикации в `main`.
4. Дождитесь успешного выполнения **Build and deploy to GitHub Pages** во вкладке **Actions**. Если workflow уже запускался до включения Pages, выполните **Re-run all jobs** или запустите workflow вручную из `main`.

Адрес после успешной публикации: **https://komradejelezo.github.io/gradus-online/**.

В Vite задан `base: "/gradus-online/"`; HTML, JavaScript, CSS и favicon собираются для этого подпути. Дополнительные секреты и токены добавлять не нужно: используется встроенный `GITHUB_TOKEN`. Право чтения репозитория задано по умолчанию, права `pages: write` и `id-token: write` получает только задача публикации. Настройки самого приложения, механика и дизайн не меняются.

## Структура

```text
src/
  App.tsx                     Навигация, сохранение, настройки и правила
  components/
    MainMenu.tsx              Стартовый экран
    PlayerSetup.tsx           Состав игроков
    Arena.tsx                 Интерактивная карта и персонажи
    GameScreen.tsx            Обычный ход и список игроков
    TaskCard.tsx              Задание, таймер и дуэль
    Dice.tsx                  Анимация кубика
    HeatMeter.tsx             Градусометр
    FinalRound.tsx            Финальный круг
    Results.tsx               Рейтинг и титулы
    Avatar.tsx, Icon.tsx       Локальная SVG-графика
    Modal.tsx                 Модальные окна
    screens.test.tsx          Тестовая отрисовка экранов
  data/
    cards.ts                  50 карточек, эффекты и 8 финальных заданий
    zones.ts                  Описание зон, палитра и аватары
  game/
    types.ts                  Типы состояния и действий
    engine.ts                 Переходы, очки, колоды и финал
    storage.ts                Валидация и сохранение
    audio.ts                  Звуки и честный бросок кубика
    engine.test.ts            Проверки правил и восстановления
  styles.css                  Оформление, адаптация и анимации
```

Чтобы расширить колоду, добавьте задание с уникальным заголовком в нужную зону в `src/data/cards.ts`. Движок автоматически включит карточки в перемешивание. Для расширения Хаоса дополните соответствующее правило в массиве `effects`. При несовместимом изменении формата сохранений обновите версию и ключ в `storage.ts`.

## Как сохранить в GitHub

Код подготовлен в существующем репозитории `komradejelezo/gradus-online`. Коммит и отправка не выполнялись.

```bash
git switch -c feat/gradus-online-v0.1
git add .
git commit -m "Build playable Gradus Online v0.1"
git push -u origin feat/gradus-online-v0.1
```

После отправки создайте Pull Request из `feat/gradus-online-v0.1` в основную ветку на GitHub. `node_modules`, `dist`, временные файлы `work/` и локальные переменные окружения исключены через `.gitignore`.
